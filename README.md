# Iron Software Technical Challange
Limitation: The overall font is Figtree, regarding of "Gotham" which is not available.

# Structure

1. All asset files has been placed in <b>public/</b> including <b>css/style.css</b> for overall styling and <b>image/</b> for images and SVG icons.
2. Home page file has been placed at <b>app/Views/homepage.php</b>

# Setup instructions

1. Install latest PHP runtime using command: <b>apt install php</b>, for macOS use <b>brew install php</b> and for Windows use <b>winget install -e --id PHP.PHP.8.4
</b>

2. Clone this repository using Git command <b>git clone https://github.com/sunny420x/iron-software-technical-challenge.git</b>

3. Go into repository folder and using command <b>php spark serve</b> to run the CodeIgniter application.

# Checklist

✅ Use the latest versions of HTML, CSS, and JavaScript.<br>
✅ Use Bootstrap (latest version) combined with clean, modular custom
CSS.<br>
✅ Use jQuery or pure JS only when necessary.<br>
✅ Convert the Figma design into a pixel-perfect, production-quality
layout.<br>
✅ Ensure responsive behaviour across all screen sizes (mobile design is
not provided, but you must make it responsive).<br>
✅ Use semantic HTML, correct headings, meta tags, alt attributes, etc.
Optimize for Core Web Vitals (CLS, LCP, FID, performance best
practices).<br>
✅ Ensure the page meets basic accessibility considerations (ARIA where
needed, keyboard navigation, contrast, etc.).<br>
